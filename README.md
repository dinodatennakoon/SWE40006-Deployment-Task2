# SWE40006 Deployment Portfolio Task 2

This repository contains the source code used for Deployment Portfolio Task 2.

## Applications

### StudentTaskManagerWeb
ASP.NET Core Razor Pages application deployed to Microsoft Azure App Service.

Features demonstrated:
- Custom C# web application
- Azure App Settings
- Health endpoint
- Azure logging
- Application Insights monitoring

### StudentTaskManagerPHP
PHP 8.5 application deployed separately to Azure App Service.

Features demonstrated:
- PHP 8.5 runtime
- Separate Linux App Service
- Deployment through VS Code Azure tools
